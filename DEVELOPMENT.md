# Game Development Overview

This repository contains documentation for game projects, concepts and development directions.

## Development Principles

### Gameplay First

Every project starts with the main gameplay loop. Core mechanics are tested before large amounts of content are created.

### Modular Architecture

Projects should separate gameplay systems, physics, AI, UI, tools and content systems whenever possible.

### Documentation

Each project should contain:

- idea description;
- gameplay mechanics;
- current status;
- development roadmap;
- technical notes.
