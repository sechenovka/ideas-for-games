# Unbound

## Genre

Scientific Space Simulation / Sandbox

## Status

Active Development

## Description

Unbound is a scientific space simulation where the player explores a world with its own laws and tools for experimentation.

The player studies cosmic systems, observes physical processes and creates experiments to understand and modify the simulated world.

## Core Features

- scientific world simulation;
- space exploration;
- physics-based systems;
- experimental sandbox gameplay;
- creation and analysis of simulated environments.
