# Arcanix

## Genre

Action RPG / Fantasy Adventure

## Status

Near Completion

## Description

Arcanix is a fantasy action RPG about a mage exploring a mysterious world, learning new spells and fighting different creatures.

The player explores locations, unlocks magical abilities and creates their own combat style through different spell interactions.

## Current Development Status

The main gameplay systems are in development/completion stage.

Remaining content:

- story integration;
- 2D models;
- animations;
- final content polish.

## Core Features

- magic system;
- spell combinations;
- physical interactions between magical effects;
- exploration;
- combat system.
