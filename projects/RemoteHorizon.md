# Remote Horizon

## Genre

Space Exploration / Automation Simulator / Sci-Fi Adventure

## Status

Concept

## Description

Remote Horizon is a sci-fi game about the first stages of human expansion into distant worlds through humanoid robotic systems.

The player controls a space expedition, manages a spacecraft and uses humanoid robots to explore planets, collect resources and build infrastructure.

Robots can be upgraded and partially automated. The player decides when to directly control them and when to create autonomous systems.

## Core Features

- humanoid robot control;
- planet exploration;
- resource extraction;
- base construction;
- robot upgrades;
- automation systems;
- space infrastructure development.
